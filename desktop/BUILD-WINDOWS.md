# ساخت برنامه دسکتاپ ویندوز (ERP ترنم — نسخه آفلاین)

نسخه دسکتاپ همان بک‌اند و رابط کاربری وب را به‌صورت **کاملاً آفلاین** روی خود سیستم اجرا می‌کند (`SYNC_ROLE=device`): پایگاه‌داده محلی SQLite در پروفایل کاربر ذخیره می‌شود و به‌محض دسترسی به اینترنت، تغییرات با سرور مرکزی همگام می‌شود.

## پیش‌نیازها (روی سیستم توسعه‌دهنده)

- **Node.js 20 یا جدیدتر** — دانلود از nodejs.org
- **ویندوز** برای ساخت نصب‌کننده ویندوز (روی لینوکس/مک هم با `--win` قابل ساخت است اما ساده‌ترین راه، ویندوز است)
- ابزارهای ساخت ماژول‌های Native (روی ویندوز): در ترمینال PowerShell با دسترسی Administrator:
  ```powershell
  npm install --global windows-build-tools
  ```
  (یا نصب Visual Studio Build Tools + Python از ویزارد نصب Node.js)

## مراحل ساخت

```bash
cd desktop
npm install          # نصب وابستگی‌ها (الکترون + همان وابستگی‌های سرور)
npm run dist:win     # کپی سورس سرور + ری‌بیلد ماژول‌های Native برای الکترون + ساخت نصب‌کننده NSIS
```

خروجی: `desktop/dist/ERP Taranom Setup 1.0.0.exe`

### اجرای آزمایشی بدون ساخت نصب‌کننده

```bash
cd desktop
npm install
npm start
```

## نکات فنی

| موضوع | توضیح |
|---|---|
| پایگاه‌داده | `%APPDATA%/erp-taranom-desktop/crm.db` (پروفایل هر کاربر ویندوز) |
| فایل‌های آپلودی | `%APPDATA%/erp-taranom-desktop/uploads/` |
| کلید JWT | برای هر نصب به‌صورت تصادفی تولید و در همان پوشه ذخیره می‌شود |
| پورت | هر بار یک پورت آزاد محلی انتخاب می‌شود — تداخلی با برنامه‌های دیگر ندارد |
| ماژول‌های Native | `better-sqlite3` و `sharp` هنگام ساخت توسط electron-builder برای ABI الکترون ری‌بیلد می‌شوند |
| به‌روزرسانی سورس سرور | اسکریپت `npm run prepare-server` هر بار آخرین سورس `../server` را کپی می‌کند — کد سرور را دو جا نگه ندارید |

## راه‌اندازی اولیه (کاربر نهایی)

1. نصب‌کننده را اجرا کنید و برنامه «ERP ترنم» را باز کنید
2. با کاربر پیش‌فرض وارد شوید: `admin` / `admin123`
3. پنجره «اتصال به سرور مرکزی» باز می‌شود — آدرس سرور (`https://erp.poshaktaranom.com`) و نام کاربری/رمز **مدیر سیستم** را وارد کنید (یک‌بار، با اینترنت). اگر «قبلاً متصل شده» دیدید: قطع اتصال و اتصال مجدد از صفحه ورود یا پنل همگام‌سازی
4. پس از دریافت اطلاعات، با نام کاربری اصلی خودتان دوباره وارد شوید — از این پس برنامه حتی بدون اینترنت کامل کار می‌کند

## عیب‌یابی

- **خطای `CopyablePersistentTraits` / `better-sqlite3` با Electron 31**: نسخهٔ قدیمی `better-sqlite3` (۹.x) با Electron 31 سازگار نیست. پاک‌سازی و نصب مجدد:
  ```powershell
  cd desktop
  Remove-Item -Recurse -Force node_modules -ErrorAction SilentlyContinue
  Remove-Item package-lock.json -ErrorAction SilentlyContinue
  npm install
  npm run postinstall
  npm run dist:win
  ```
  در `package.json` باید `"better-sqlite3": "11.10.0"` (دقیق) باشد — نه `^9.x`.
- **خطای ساخت better-sqlite3**: مطمئن شوید Build Tools ویندوز نصب است؛ سپس `npm install` را دوباره اجرا کنید
- **برنامه باز می‌شود ولی صفحه سفید است**: چند ثانیه صبر کنید (سرور داخلی در حال بالا آمدن است)؛ اگر ادامه داشت از منوی View → Reload استفاده کنید
- **همگام‌سازی انجام نمی‌شود**: نشانگر وضعیت بالای صفحه را بزنید — آدرس سرور مرکزی و اتصال اینترنت را بررسی کنید
- **خطای `Persian.nlf` هنگام ساخت نصب‌کننده**: نصب‌کننده NSIS به‌صورت پیش‌فرض به زبان انگلیسی ساخته می‌شود (تنظیم `installerLanguages` عمداً حذف شده تا NSIS دنبال فایل زبان فارسی نگردد). خود برنامه کاملاً فارسی است — فقط پنجرهٔ نصب انگلیسی است. اگر این خطا را دیدید یعنی نسخهٔ قدیمی‌تر config را دارید
- **خطای دانلود باینری `better-sqlite3` (۴۰۳/شبکه)**: باید روی سیستمی با دسترسی به GitHub ساخت بزنید؛ `prebuild-install` باینری ویندوزی را از GitHub Releases می‌گیرد یا با Visual Studio Build Tools از سورس می‌سازد
