# Project Overview

- Purpose: Iranian ERP/CRM platform with accounting, sales/marketing representatives, B2B and operational portals.
- Users/stakeholders: system owner, internal staff, sales representatives, B2B customers and operations administrators.
- Technology stack: Node.js/Express backend with SQLite, browser frontend, Android wrapper and Electron desktop client.
- Deployment environments: Windows development/build PC and Linux VPS production managed by PM2.
- Source of requirements: repository documentation under `docs/`, Wave 0 plan, committed tests and owner instructions.

Only facts verified from repository evidence or production read-only checks may replace or extend this summary.
