## 📞 نکات مهم برای حامد

1. **قبل از هر deploy، بکاپ بگیر.** این ماژول با دفتر کل کار می‌کند.
2. **اولین بستن ماه را دستی هم حساب کن** و با PR-23 مقایسه کن.
3. **از ماژول ۲ شروع کن، نه ۸.** پیچیدگی زودرس پروژه را می‌کشد.
4. **نرخ سربار را ماهانه بازنگری کن** — تورم ایران نرخ‌ها را زود کهنه می‌کند.
5. **`production_estimate_price_basis = 'max'`** را دست نزن — در تورم `average` تو را ضرر می‌دهد.
6. **سقف تخفیف ۲۰٪ خطرناک است** — نقطه شکست ۲۴.۲٪ است، فقط ۴ واحد فاصله.
7. **ویزیتور نباید بهای تمام‌شده را ببیند** (C-17) — این را تست کن.
8. **ماتریس انحراف (ماژول ۸) را در جلسه هفتگی بگذار** — بیشترین ارزش مدیریتی اینجاست.
