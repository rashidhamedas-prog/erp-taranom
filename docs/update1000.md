ERP & Accounting System - Feature Requirements & Bug Fixes
1. UI/UX & Global Changes
Number Formatting: Globally across the entire application, format number inputs with thousand separators (e.g., 1,000,000) dynamically as the user types.
2. Dashboard & General Ledger
Merge Dashboards: Merge the "Accounting Dashboard" and "General Ledger Dashboard" into a single unified section.
Chart of Accounts Categorization: In the "General Ledger" section, accounts must be properly categorized and fully listed.
Manual Account Creation: Add the ability to manually create/add new accounts directly within the "Account Coding" (Chart of Accounts) subsection.
3. Receivables & Receipt Operations
Customer Receivables:
Rename the "Register Settlement" option to "Register Payment".
Add the ability to record multiple payment installments/stages within this option.
Receipt Operations:
Rename the "New Settlement Registration" option to "Register Payment".
Add the ability to select specific invoices.
Add the ability to record multiple payment installments/stages.
4. Purchases & Petty Cash
Purchase Invoices:
Bug Fix: In the "New Purchase Invoice" option, the product list is not displaying. This needs to be fixed.
Inline Product Creation: Add the ability to create a new product directly from within the Purchase and Sales Invoice interfaces without navigating away.
Petty Cash: In the "Register Expense" option:
Add the ability to select the expense account directly from the General Ledger.
Add the ability to link the payment to a specific Purchase Invoice.
5. Products, Warehouses & Inventory
Product Categories: Add a dedicated section/feature to add and manage product categories.
Warehouse Integration: Link the "Warehouses" section to the "Products" section.
Add a feature in the "Products" section to view and separate product inventory across different warehouses.
Add the ability to select the destination warehouse when registering a production execution order.
6. Advanced Production & Overhead Costing
Production Execution: Develop a highly advanced "Production Execution" module.
Automated Overhead Calculation: Implement a professional, principled method to automatically and accurately calculate the overhead cost per produced item. This should be done either by:
Implementing a tagging/labeling system to mark specific expenses as "overhead".
Or utilizing any other standard cost-accounting logic to automatically allocate overhead costs to production batches.
7. Payroll System
Farankenou Integration: Add the ability to import and read attendance files generated by the "Farankenou" software.
Automated Payroll Calculation: The system should read the uploaded Farankenou attendance file, calculate the payroll for each employee automatically, and upon user approval, automatically generate the corresponding payroll accounting vouchers.
Field & Internal Experts Auto-Payroll: Enable automatic salary registration for field and internal experts. The calculation method should be based on base information defined partly in the "User Creation" section, with the remaining variables completed in the "Payroll" section.
8. Manual Accounting Vouchers
Account Search: In the "New Manual Voucher" option, add a search/filter functionality to easily find and select accounts while building the voucher.
9. Bug Fixes (Desktop vs. Web Sync)
Data Deletion & Sync Issue (Windows Desktop App):
Problem: When registering a customer in the Windows desktop version and then attempting to delete it, the system throws a "Not Found" error even though the customer exists.
Secondary Issue: Deleting the customer via the Chrome (web) browser works, but the customer still visibly remains on the Windows desktop application despite running the software's synchronization feature.
Required Fix: Ensure deletion is propagated correctly across the local desktop cache/database and fix the sync mechanism between the web app and the Windows desktop client.
