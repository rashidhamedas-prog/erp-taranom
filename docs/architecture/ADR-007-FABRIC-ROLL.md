# ADR-007 Amendment — طاقه / Lot پارچه (بازگشایی محدود)

**وضعیت:** Proposed (باز شده ۱۴۰۵/۰۵/۲۹ / 2026-08-20) — هنوز Accepted نیست.  
**مالک تصمیم:** صاحب محصول ERP ترنم  
**مرتبط:** `docs/Production/Production-Master-Architecture.md` ADR-007 اصلی، نیازمندی Stitch **PROD-01**  
**کد محصول این نوبت:** هیچ — فقط سند تصمیم. پیاده‌سازی طاقه/برش بعد از Accept مالک در Task جدا (`PROD-STITCH-P5`).

## Context

ADR-007 اصلی می‌گوید انبار **معمولی** است: بدون Lot / Serial / Bin، با سه انبار منطقی `WH-RAW` / `WH-FG` / `WH-SUB` و WIP به‌صورت حساب کنترلی (نه انبار فیزیکی).

نیازمندی تأییدشدهٔ Stitch (**PROD-01**، Frame BASE-16) برای پوشاک ترنم طاقه پارچه با رنگ / طرح / متر می‌خواهد. این با «بدون Lot» در تضاد است. جدول موجود `inventory_batches` برای تاریخ انقضا/کیفیت است، نه هویت طاقه پارچه (رنگ، عرض، متر باقی‌مانده).

مالک قبلاً تولید/پک را عقب انداخت تا ADR-007 باز نشود. این سند همان بازگشایی است.

## Decision (پیشنهاد — منتظر Accept)

1. **FG پوشاک (مانتو/شومیز آماده فروش):** ADR-007 اصلی پابرجا است — موجودی در Grain کالا + انبار، **بدون Lot و بدون Serial**.
2. **مواد اولیه پیوسته (پارچه و مشابه در `WH-RAW`):** استثناء محدود — هویت **طاقه (roll)** مجاز است: `roll_no`، رنگ، shade، عرض (سانتی‌متر)، متر روی دست. این Lot نساجی است نه سریال تک‌قلم پوشاک.
3. **Bin / جای قفسه:** همچنان ممنوع.
4. **Serial روی کالای آماده فروش:** همچنان ممنوع.
5. جدول فیزیکی پیشنهادی: گسترش افزایشی `inventory_batches` (ستون‌های پارچه) یا جدول `fabric_rolls` جدید؛ موجودی طاقه از Stock ledger با `batch_id`/`roll_id` خوانده می‌شود. ویرایش مستقیم `products.stock` ممنوع می‌ماند.
6. سه انبار منطقی و WIP حسابی **تغییر نمی‌کنند**.
7. تا Accept مالک، هیچ مهاجرت schema برای طاقه merge/deploy نمی‌شود.

## Consequences

- فاز ۵ Stitch (PROD-01 تا PACK-02) فقط بعد از Accept این ADR شروع می‌شود.
- سخت‌سازی فاز ۸ این نوبت روی موج‌های حسابداری تا LED/POS است، نه روی طاقه.
- اگر مالک Reject کند، PROD-01 به تعویق می‌ماند و BASE-16 فقط visual بدون backend طاقه است.

## Rollback

- قبل از Accept: حذف همین فایل از شاخه.
- بعد از Accept و قبل از کد: برگرداندن وضعیت به Accepted-superseded-by-reject.
- بعد از کد: ستون افزایشی می‌ماند؛ رفتار با flag خاموش می‌شود — حذف فیزیکی اسناد مالی ممنوع.

## سوال مالک برای Accept

آیا طاقه پارچه فقط روی `WH-RAW` فعال شود و کالای ساخته‌شده بدون Lot بماند؟ (پیشنهاد: بله)
