> این سند خروجی Phase 0 skill-top + تکمیل کم‌وکاستی‌های درخواست مالک است.
> عمق: **کامل**. موج جاری: **W1 (SW v470)** انجام‌شده؛ W2–W4 در صف.

## Goal
مسیر **BOM per محصول → سفارش ۱/N محصول → لایه‌چینی (تک یا مشترک) → گیت برش → مراحل → پک/رسید → انبار** طوری کار کند که همهٔ رویدادهای مؤثر در بهای تمام‌شده تا لحظهٔ رسید لحاظ شوند، تسهیم لای مشترک قابل‌انتخاب باشد، و هر مرحله Edit+Void کامل (R13) داشته باشد.

## Acceptance (کل برنامه)
1. سفارش تک‌محصول و چندمحصول؛ هر محصول BOM مستقل
2. لای مشترک چندمدلی با تعداد برش جدا + مصرف/ضایعات/انحراف
3. تسهیم: `pieces | fabric | manual | hybrid` قابل انتخاب
4. عبور از برش فقط بعد از پوشش لای (W3)
5. `cost_final` فقط با لای لازم + مسیر + رسید؛ نه فقط WIP متوازن
6. بعد از انبار: قفل بها + اصلاح با ابطال رسید یا اختلاف‌بها (ADR-006 §۳)
7. R13 همهٔ مراحل؛ بدون مسیر UI/کد مرده
8. تست‌ها + Help + CHANGE-LOG + deploy ایران

## Constraints
استک فعلی؛ R1–R13؛ sync append-only؛ بدون بیلد APK مگر درخواست؛ درس‌های v427–v469 تکرار نشوند.
