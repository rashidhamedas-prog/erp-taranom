# آزمایشگاه UI/UX ترنم

این نمونه بدون build و بدون وابستگی اجرا می‌شود: فایل `index.html` را در مرورگر باز کنید.

سه مسیر بصری قابل اجرا دارد: «مرکز فرمان» برای مدیرعامل، «میز مالی» برای حسابدار و «فروش میدانی» برای نماینده فروش. تغییر مسیر طراحی، حالت تاریک، جست‌وجوی سریع، فیلتر، منوی موبایل و CTA ثبت سند تعاملی هستند؛ داده‌ها نمونه‌اند و عمداً به API واقعی وصل نشده‌اند تا قبل از تأیید طراحی، رفتار production تغییر نکند.

## بررسی UI فعلی

کد فعلی پایه خوبی دارد: RTL، Vazirmatn، responsive breakpoint، sidebar، topbar، حالت تاریک، nav حسابداری و componentهای تولید. مسئله اصلی ناهماهنگی تجربه در سطح محصول است: تراکم زیاد منوها، رقابت رنگ بنفش/سبز/طلایی، نبود hierarchy واحد برای KPIها، وابستگی زیاد به `innerHTML` و inline handler، و تفاوت mental model بین مدیر، حسابدار، فروشنده و اپراتور.

## جهت پیشنهادی production

جهت پیشنهادی «مرکز فرمان عملیاتی ایرانی» است: سبز جنگلی برای اعتماد، کرم گرم برای canvas، طلایی فقط برای اقدام یا هشدار مهم، Vazirmatn، sidebar قابل جمع‌شدن، command palette، KPIهای نقش‌محور و progressive disclosure برای منوهای عمیق. قبل از انتقال به `server/public/index.html` باید با کاربران نهایی یکی از سه مسیر، نقش اولویت‌دار و ترتیب منوی اصلی تأیید شود؛ سپس prototype به token/componentهای production و تست screenshot/keyboard/mobile منتقل می‌شود.
